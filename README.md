## Purpose

## Team Development
チームで作業するときは、作業ごとにブランチを作成します。

変更内容はPull Requestで確認してからmainに取り込みます。

Pull Requestを作成したら、他のメンバーに変更内容を確認してもらいます。
コメントや修正依頼があった場合は、内容を確認して必要な修正を行います。
